# qrmo

مولّد أكواد QR احترافي، مجاني بالكامل، ويعمل بالكامل داخل المتصفح — من غير سيرفر ومن غير تسجيل.

**تجربة مباشرة:** `https://iegy.net/qr/`

## المميزات

- **7 أنواع محتوى:** لينك، نص، واي فاي، جهة اتصال (vCard)، إيميل، تليفون، رسالة SMS، وموقع جغرافي.
- **تخصيص كامل:** لون الكود والخلفية (تدرّج لوني اختياري)، خلفية شفافة، شكل النقط، شكل حدود ومركز الزاوية، مستوى تصحيح الخطأ، لوجو في نص الكود (بيرفع مستوى تصحيح الخطأ تلقائيًا)، وإطار "امسحني" اختياري.
- **تحقّق تلقائي من قابلية القراءة:** فحص تباين الألوان + إعادة قراءة الكود المولَّد فعليًا (jsQR) قبل ما تنزّله، مع تحذير لو في مشكلة.
- **أكوادي المحفوظة:** احفظ تصميمات كاملة (بيانات + تنسيق) محليًا على جهازك وارجعلها وقت ما تحب.
- **تحميل PNG أو SVG.**
- **توليد بالجملة:** رفع ملف `.txt`/`.csv` (CSV حقيقي، بيدعم القيم بين علامات تنصيص) أو لصق قايمة، وتحميل كل الأكواد كملف ZIP أو طباعتها كشيت واحد.
- **قارئ أكواد:** مسح من كاميرا الجهاز أو من صورة مرفوعة، مع تفسير المحتوى (رابط، واي فاي، جهة اتصال...)، وسجل مسح بيتحفظ على الجهاز مع تصدير CSV.
- **عربي/إنجليزي:** تبديل فوري للغة الواجهة بالكامل (بيتذكّر اختيارك)، من غير ما يأثر على الروابط ولا الرؤية على محركات البحث.
- **وضع ليلي/نهاري:** زرار في النافبار يبدّل بين الوضعين فورًا وبيتذكّر اختيارك.
- **يعمل Offline ويتثبّت كتطبيق (PWA):** بعد أول زيارة، الموقع بيشتغل من غير إنترنت وتقدر تضيفه لشاشتك الرئيسية.
- **خصوصية كاملة:** كل التوليد والقراءة بيتم عن طريق JavaScript في متصفح الزائر، مفيش أي بيانات بتتبعت لأي سيرفر.

## البنية

كل الملفات flat في نفس المجلد (من غير خطوة build ولا bundler):

```
qrmo/
├── index.html            الصفحة الرئيسية
├── generator.html        المولّد الفردي
├── batch.html             التوليد بالجملة
├── scanner.html           قارئ الأكواد
├── about.html             عن qrmo
├── style.css              كل الأنماط
├── qr-core.js             بناء بيانات كل نوع + تغليف مكتبة qr-code-styling + فحوصات القراءة
├── i18n.js                نظام تبديل اللغة (عربي/إنجليزي)
├── main.js                سلوك مشترك (قائمة الموبايل، تسجيل الـ service worker، إلخ)
├── home.js / generator.js / batch.js / scanner.js   منطق كل صفحة
├── sw.js                  service worker (تشغيل offline + تثبيت كتطبيق)
├── manifest.json          بيانات الـ PWA
├── favicon.svg / favicon-32.png / apple-touch-icon.png / icon-192.png / icon-512.png / icon-512-maskable.png
├── og-image.png           صورة المشاركة على السوشيال ميديا
├── robots.txt / sitemap.xml
└── README.md
```

## التقنيات المستخدمة

- HTML / CSS / JavaScript عادي (بدون أي إطار عمل أو خطوة بناء)
- [qr-code-styling](https://github.com/kozakdenys/qr-code-styling) لتوليد وتخصيص أكواد QR (بما فيها التدرّجات اللونية)
- [JSZip](https://stuk.github.io/jszip/) لتجميع أكواد التوليد بالجملة في ملف ZIP
- [jsQR](https://github.com/cozmo/jsQR) لقراءة أكواد QR من الكاميرا أو الصور، وكمان للتحقق التلقائي من قابلية قراءة الأكواد المولَّدة

## النشر

1. ارفع كل الملفات كما هي (من غير مجلدات فرعية) لأي استضافة استاتيك — GitHub Pages، Netlify، Cloudflare Pages، أو أي سيرفر ويب عادي.
2. لو غيّرت الدومين عن `https://iegy.net/qr/`، دوّر على السطر ده في الملفات وحدّثه: `<link rel="canonical" ...>`, `og:url`, `sitemap.xml`, و`robots.txt`.
3. الموقع مبني بحيث يشتغل offline بعد أول زيارة بفضل الـ service worker (`sw.js`) — لو غيّرت أي ملف استاتيك، زوّد رقم `CACHE_VERSION` في `sw.js` عشان الزوار ياخدوا النسخة الجديدة.

## ملاحظة عن اللغة الإنجليزية

زرار تبديل اللغة في النافبار بيغيّر نص الواجهة فورًا في المتصفح ويحفظ الاختيار، لكن الصفحة المصدر (وبالتالي الـ SEO/الفهرسة) لسه عربي بالكامل. لو عايز نسخة إنجليزية قابلة للفهرسة فعليًا على جوجل، محتاج صفحات منفصلة تحت مسار زي `/en/` مع `hreflang` — ده مشروع أكبر من مجرد toggle.
